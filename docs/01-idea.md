# ClubTasker – Project Idea

## Project Name

ClubTasker

## Short Description

ClubTasker is a web application for a club, school group, or team. The app helps members organize events and tasks.

Users can see upcoming events, view open tasks, take responsibility for tasks, and mark tasks as completed.

## Problem

In many clubs or school groups, tasks are often managed through chat messages or verbal communication. This can become confusing because members may forget who is responsible for which task.

## Solution

ClubTasker provides one central place where events and tasks are visible to all members.

## Main Features

- Users can log in.
- Users can view events.
- Users can view tasks.
- Users can take over a task.
- Users can mark a task as completed.
- Admins can create events.
- Admins can create tasks.

## Why this is a good pet project

This project is bigger than a simple ToDo app because it includes users, events, tasks, roles, a frontend, a backend, and a database.

It is also still small enough to understand and explain completely.
