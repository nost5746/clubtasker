# AI Prompts

This document contains the prompts and AI-supported steps used during the development of the ClubTasker project.

## Goal

The goal was to create a small but realistic full-stack web application with a graphical user interface, a backend, separate modules, and clear documentation.

## Initial Project Prompt

The following idea was used as the basis for the project:

"Create a project idea for a beginner-friendly but still meaningful full-stack web application. The application should have a graphical user interface, a backend, a database concept, and separate modules. It should be suitable as a medium-sized pet project and easy to explain."

## GUI Design Prompt

The following prompt was used to design the user interface idea:

"Create a modern web app UI for a club task and event manager called ClubTasker. The app should have a clean dashboard, a sidebar navigation, an event overview, a task overview, and a visible backend connection status. Use cards, clear sections, and status badges for tasks like open, in progress, and done."

## Frontend Implementation Prompt

The following prompt was used to transform the GUI idea into a React frontend:

"Create a React frontend for ClubTasker. The frontend should show a sidebar, a dashboard section, event cards, task cards, and a backend connection status. It should fetch event data from http://localhost:3000/api/events and task data from http://localhost:3000/api/tasks."

## Backend Implementation Prompt

The following prompt was used to create the backend structure:

"Create a beginner-friendly Express backend for ClubTasker. The backend should provide API routes for events and tasks. The code should be separated into routes, controllers, and models so that the application consists of clear modules."

## Documentation Prompt

The following prompt was used to create understandable documentation:

"Explain the ClubTasker project step by step for a beginner. Describe the project idea, the architecture, the module structure, the API routes, and how the frontend communicates with the backend."

## Result

The prompts helped to develop the project idea, the graphical user interface, the backend structure, and the documentation.

The final application consists of a React frontend and an Express backend with separate modules.
